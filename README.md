# Car-Shop | Elecar

A responsive electric vehicle landing page inspired by the original Elecar design. This project focuses on improving code organization, maintainability, and development workflow while preserving the original visual identity.

The codebase uses modular HTML, CSS, and JavaScript, with a structure designed to support future development and a potential migration to React.

## Design

**Original Figma Design:**
[View the Elecar Design on Figma](https://www.figma.com/design/MXqnlCWUwEngNeBlEXZy7p/Figma-Design-Responsive-car-website--Community-?t=ANHyHu8PXBvGjg6L-0)

## Features

- Responsive layouts for desktop, tablet, and mobile devices
- Interactive mobile navigation menu
- Hero section featuring an electric vehicle and key statistics
- About, Popular, Featured, and Special Offers sections
- Brand showcase and footer
- Locally stored images, SVG icons, and other visual assets
- Modular CSS architecture for improved maintainability
- JavaScript modules for organizing interactive functionality
- Vite-powered local development and production builds
- Project structure prepared for future React integration

## Technologies

- **HTML5** — Semantic page structure
- **CSS3** — Flexbox, Grid, responsive layouts, and media queries
- **JavaScript (ES Modules)** — Interactive functionality and modular code organization
- **Vite** — Local development server and production build tooling
- **Swiper** — Interactive sliders and carousels
- **Google Fonts** — Typography
- **Git & GitHub** — Version control and project hosting
- **GitHub Pages** — Live project deployment

## Local Development

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm, which is included with Node.js

### 1. Clone the Repository

```bash
git clone https://github.com/00mohammad/Car-shop.git
```

### 2. Navigate to the Project Directory

```bash
cd Car-shop
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

### 5. Build for Production

```bash
npm run build
```

Vite generates the production-ready files in the `dist/` directory.

### 6. Preview the Production Build

```bash
npm run preview
```

Open the preview URL displayed in your terminal, usually:

```text
http://localhost:4173/
```

## Deployment

The project is designed to support deployment through GitHub Pages.

Before deploying, ensure that the Vite configuration, asset paths, and deployment base path are configured correctly for the repository.

For repository-based GitHub Pages deployment, the Vite `base` option may need to match the repository name:

```js
export default {
  base: "/Car-shop/",
};
```

Use this configuration only when the deployed site is served from the `/Car-shop/` path. For a root-domain deployment, the base path may differ.
